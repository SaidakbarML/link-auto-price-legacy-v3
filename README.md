# Link Auto Price (Legacy v3)

Third iteration of the car price prediction model — despite the original "final" in its name, it was superseded by the current `link-auto` repo (pushed more recently).

## Why this exists
Kept for historical reference as part of the auto price prediction pipeline's evolution.

## Tech stack
Python, Jupyter Notebook, LightGBM

## How to run
1. `pip install -r requirements.txt`
2. `python app.py`, using `CHEVROLET_DAEWOO_RAVON_LGBM_extra.pkl` and `Car_State_name.csv`

**Note:** this is a legacy version — check `link-auto` for the current, actively maintained pipeline.
